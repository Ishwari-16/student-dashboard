# Student Learning Dashboard

A production-ready student learning dashboard built with Next.js 15 App Router, TypeScript, Tailwind CSS, Framer Motion, and Supabase.

## ✨ Features

- **Modern Dark Theme** - Futuristic design inspired by Linear, Vercel & Notion
- **Bento Grid Layout** - Premium card-based dashboard
- **Server-Side Data Fetching** - Using Supabase SSR
- **Smooth Animations** - Framer Motion with spring physics
- **Responsive Design** - Desktop, tablet, and mobile layouts

## 🏗️ Architecture

### Server vs Client Components
- **Server Components**: Data fetching in `page.tsx`
- **Client Components**: Interactive UI with `use client`
